# compose

Spec-driven development workflows for coding engines (Claude Code first), with a CLI, an HTTP
API, workflow hooks, and per-step traceability, cost and change tracking.

Status: early development. See the [design](docs/superpowers/specs/2026-11-21-compose-design.md)
and the [implementation plan](docs/superpowers/plans/2026-11-21-compose-plan.md).

## Development

```bash
uv sync
uv run pytest
uv run ruff check
```
